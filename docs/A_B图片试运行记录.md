# A/B 图片试运行记录

2026-10-01 使用本机配置的 `qwen3.8-flash` 调用真实视觉接口，对官方 A 组 3 张、B 组 4 张图片逐张试跑。原始 JSON 存于本地忽略目录 `outputs/pilot-A-*.json` 和 `outputs/pilot-B-*.json`，没有上传原图或原始输出。这里仅记录模型输出的风险候选，**没有官方逐图真值，不能计算准确率，也不能把候选当作最终核保结论**。

| 图片 | 本次主要候选 | 需要核对的地方 |
| --- | --- | --- |
| A-1 | 未报告农业、渔业、涉水环境；易燃物不确定 | 画面是屋顶全景，易燃物不是这一材料类别的直接判断依据；须核实视角和水印时效。 |
| A-2 | 未报告农业、渔业、涉水环境；易燃物已发现 | 易燃物类别来自全景照，规则引擎按材料类别过滤，不据此自动加费或拒保。 |
| A-3 | 图片质量异常；线缆风险不确定 | 应由人工确认是否属于电气材料及质量异常是否属实，不能按全景照对待。 |
| B-1～B-4 | 多张报告农业、渔业或涉水环境风险候选 | 需逐图核对环境类别、证据区域与官方预期动作；候选不等于已验证拒保事实。 |

同一张 A-1 图片单独调用与批量试跑的输出曾不一致，说明模型结果存在运行波动。后续必须先取得 A/B 每张图的材料类别、拍摄视角、风险标签和预期动作，再冻结提示词与规则版本、重复评测并记录误报与漏报。C 组材料及真值目前也未取得。

官方规则表的中期检查（包括无保护裸露线缆拒保）当前默认关闭。业务确认启用范围后，可修改 `data/rules/challenge_open_ai_01.json` 的 `advanced_checks_enabled`，并用标注样本重新验证。
