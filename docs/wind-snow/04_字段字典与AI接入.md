|---|---|---|
| project_id | string | 可选案件/项目标识 |
| model | string | 完整组件型号；OCR识别后确认，不借用近似型号 |
| address | string | 项目所在地地址；案件地址为权威输入 |
| screening_input.site.province | string | 可选省名，帮助消歧 |
| screening_input.site.city/district | string | 可选来源城市名/区县信息；非全量行政区编码服务 |
| screening_input.site.source_record_id | string | 可选明确选取测站记录ID，来自catalog |

| ai_geometry.height_m.min/max | number，m | 组件计算高度的估计区间，非支架自身高度；大于0 |
| ai_geometry.height_m.source | string | 必填来源/估计依据 |
| ai_geometry.tilt_deg.min/max | number，° | 安装倾角区间0～55° |

## AI识别接入建议
当前模块不新增独立照片识别接口。由现有照片/OCR/多模态流程输出安装参数，映射到ai_geometry后调用计算。材料不足时返回缺值，不编造默认高度、倾角或粗糙类别。
- 高度：注明参照物、照片ID、是否看到地面和组件；透视或楼层尺度不确定时输出区间，无法判断则转人工。
- 倾角：注明拍摄视角、坡面参照和估计范围，不能直接将照片画面角度当实际倾角。
- 粗糙度：依业务确认的类别描述与周边证据输出候选，不仅凭屋顶近景选一个类别。
- 可在source中记录照片编号、人工确认和估计理由；原图框选及像素位置应由现有照片模块保存，风雪模块不假称已实现几何测量。

示例任务提示：仅提取组件计算高度、组件相对水平面的倾角、周边粗糙类别候选及证据。无法判断的字段留空并列出补拍建议，不输出风雪等级，不编造系数或能力。经业务确认后按本字段合同提交确定性计算。

## 输出
assessment.wind/snow：status、load_pa(min/max)、capacity_pa、comparison_ratio、comparison_percent、risk_level、risk_label、trace。
缺项时不保证这些数值字段存在，应读reason并显示待评估。
assessment顶层：model_version、location_match、component_capacities、status、data_complete、risk_level、known_max_risk_level、thresholds、actions、limitations、input_snapshot、requires_manual_review、can_auto_approve。
unknown/low/medium/high/critical分别为待评估/低/中/高/极高。can_auto_approve始终false。
2026-10-16 本地整案口径：`data_complete=true`、整体 `risk_level=low`、`status=NOT_EXCEEDED`、无跨档时，`requires_manual_review=false`，仅作提示；其余状态由风雪专项触发复核。`can_auto_approve=false` 只表示本模块不能单独给出承保结论，不覆盖整案决策引擎。
