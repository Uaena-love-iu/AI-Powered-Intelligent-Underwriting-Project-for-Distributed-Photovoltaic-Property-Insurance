# 文件与维护
核心模块路径：source/backend/app/catastrophe/front_load_screening/。
unified.py为统一业务入口；city_engine.py为荷载计算；city_lookup.py为地址匹配；city_rules.json为系数表；data/city_wind_snow.json为本地压力数据。
规则阈值：source/data/rules/challenge_open_ai_01.json。
HTTP接口：source/backend/app/api/unified_risk.py。
报告：source/backend/app/reports/generator.py、source/frontend/underwriting-report.js。
整单：source/backend/app/pipeline/core.py、source/backend/app/decision/engine.py。

source包含必要公共数据及依赖模块，保留部分旧接口用于历史兼容。新接入只调用unified入口，不调用旧engine.evaluate当成新版结果。

发布新版本：修改规则/数据→添加边界测试→运行离线及接口验收→更新VERSION和规则版本→重新导出示例→生成SHA256→记录业务确认。证据链接失效、参数冲突或城市缺值应记录待核查，不补造能力或气象数据。

SHA256校验方法：Python逐行读取manifest.sha256，对对应相对路径文件计算hashlib.sha256。清单不包含自身、ZIP及运行后产生的local_output。使用者运行后新增日志/虚拟环境不属于交付快照。
