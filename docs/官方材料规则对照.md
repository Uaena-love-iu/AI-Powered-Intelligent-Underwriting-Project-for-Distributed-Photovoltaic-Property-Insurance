## 验收所需输入

1. 业务负责人逐条确认上述初期/中期适用范围、缺失材料动作和拒保条件。
2. A/B 每张图的材料类别、视角、风险标签、预期动作；C 组材料和完整真值。
3. 高火险行业名单、监控优惠、加费、保费和灾害阈值的正式依据。
4. 组件铭牌或采购资料，核对设备清单写法 `JAM72D42-630W` 与厂商 `JAM72D42-630/LB` 是否为同一型号。

在上述真值或正式依据缺失时，结果保持补材或人工复核，不用推测值填充规则或计算保费。
