# 参数查询 API 升级与实测

日期：2026-10-11。当前工作台：http://localhost:8768/risk-lab。

## 本次做了什么

目标是减少基本组件参数与气象背景字段的缺失，验证查询是否真实取得数据，并明确哪些字段仍不能可靠取得。参数查询已升级并接入当前工作台；本次结果不代表完整抗灾量化或最终核保规则已经验收通过。

### 组件查询

1. 原 Solar Stack 查询固定过滤 `GLOBAL` 市场，晶澳美国版完整型号即使存在也查不到。现在 GLOBAL 未命中时查询区域版本；保留完整后缀、厂家与市场信息，唯一精确匹配才返回数值。
2. 原代码仅映射功率、静载和冰雹试验字段，遗漏 API 已返回的电压、电流、尺寸、重量、系统电压、保险丝额定电流等；现在保存这些字段以及温度系数、工作温度、双面率、系列、电池技术、更新时间和资料链接。
3. 新增 23 个经厂家原始 PDF 图像核对的完整型号：晶澳 12 个、阿特斯 8 个、隆基 3 个。每个数值记录来源 URL、PDF 页码、文件 SHA256、资料版本和表格上下文；只录入表中明确型号，不外推功率。
4. 各版本作为整条记录处理。不将美国/澳洲参数塞进中国版目录；同版本冲突保留本地值并提示核对。厂家资料以 STC 列为准，不拿 NOCT/NMOT 或背面增益行代替。
5. 引入 SQLite 缓存，Provider 每次重建也能复用；正命中默认缓存 24 小时，未匹配最多 1 小时。
6. 新增 `GET /api/v1/components/lookup?model=...`，返回 `profile`、12 项基本字段覆盖、逐字段单位/来源/缺失原因，以及未匹配时的型号候选。候选不能参与核保。

12 项基本字段：额定功率、开路电压、最大功率电压、短路电流、最大功率电流、长/宽/厚、重量、电池片数量、最大系统电压、最大串联保险丝额定电流。这是本次实现的基础查询口径，尚不是团队最终确定的抗灾参数清单。

### 气象查询

1. 统一历史查询、抗灾调试和整单 WeatherProfile 的数据入口，使用固定 ERA5 背景和独立 ERA5-Land 地面积雪资料。
2. 取得 14 类小时字段：风速、阵风、风向、温度、相对湿度、露点、地表气压、海平面气压、降水、降雨、降雪、云量、短波辐照、地面积雪深度。
3. 支持逐小时最多 2 年、日/年汇总最多 20 年。服务端自动按年分段；支持超时/临时故障重试，缓存于本机 `outputs/provider-cache.sqlite3`。完整数据默认缓存 30 天，缺字段/部分数据 5 分钟后可重新查询。
4. 返回逐字段单位、来源、有效小时数，逐年覆盖、阵风峰值时间和当时风向。温度允许负数，真实零值与未知分别处理；不做缺失数据补零。
5. 逐年记录说明完整日历年、应有小时数、逐字段可比状态。不完整年份保留已取得最大值与部分合计，明确不能直接作为完整年度样本。单位不匹配仅失效对应字段；某年份或积雪服务失败时其他数据保留，缺口单独标注。
6. 整单保存年度摘要、基本参数覆盖和来源；原始小时数据存于服务端缓存，需要时通过历史接口导出。页面的“基本气象、逐年记录与完整性”可查看本次结果。

短波辐照以小时平均 W/m² 积分为 kWh/m²，不能直接称为组件发电量。风向采用圆周平均，避免将 350° 与 10° 错算成 180°。

5 个有效型号全部取得 12 项基本参数；1 个未匹配输入没有被虚构为成功。`JAM66D42-715/MB` 只证明目前查询源未精确匹配，不能据此断言该型号绝对不存在。应核对原始铭牌和完整型号。

阿特斯 PDF 文件名含 TX90，但表内双面率实际为 **85%**，按表内数值记录；功率公差为 **10 W**，不误记为 10%；NMOT 41°C 不冒充 NOCT。

- Python 单元测试及参数、历史气象、基础接口测试：457 项通过。
- 既有前端测试：3 个测试文件通过；两处新增/修改的 JavaScript 通过语法检查。
- 新增测试验证：区域回退、完整后缀、分页、跨版本禁止拼接、冲突提示、STC/NMOT 区分、功率公差单位、跨 Provider 缓存、负温/零值、单位错误、次数据源失败、年份失败、闰年覆盖、重复时间戳、整单 WeatherProfile 摘要。
- 运行中的 8768 服务已验证组件统一查询、旧抗灾组件接口、历史气象接口和抗灾 WeatherProfile 接口；网页按钮实际查询并显示电气/机械参数、十年记录和覆盖结果。
- 不声称整个核保系统全部测试通过。另跑整单集成测试时，既有 `test_runs_complete_real_underwriting_pipeline` 仍因 `catastrophe_assessment.comparisons` 为空而失败；查询字段本身已传入案件。这是原有抗灾结果持久化/整合问题，本次没有改拒保规则或伪造抗灾等级。

## 仍存在的真实缺口

- 中国电站的历史冰雹事件与最大直径：目前没有接入可核验的对应数据源。本次未取得，仍为未知；不把次数、雷暴或天气代码充当冰雹直径。
- 屋面雪荷载：不能由降雪量或地面积雪深度直接替代，缺少积雪密度、屋面形状、风吹堆积及结构设计等依据。
- 安装配置对应的组件设计风压/雪荷载：厂家正背面静态试验载荷不自动转成工程能力，需要安装手册和固定方式证据。新增基本规格不意味着这两项已经补齐。
- 北美、GLOBAL 资料是否适用于具体中国项目仍需铭牌、资料版本确认。系统展示市场边界，并不据此确认实际设备配置。
- 新本地补充目录覆盖 23 个经核对型号；其他型号仍依赖原目录与在线源。查不到时会说明原因，不保证任意输入都能找到。

因此，本次完成了参数查询升级和自测，**尚不能宣称整套抗灾风险量化已经闭环**。下一阶段需单独确定分灾种必需字段、安装适用条件和缺证据时的业务动作。
