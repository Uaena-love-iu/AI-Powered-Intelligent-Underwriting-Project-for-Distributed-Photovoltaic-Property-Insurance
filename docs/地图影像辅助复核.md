# 高德卫星影像辅助复核

## 适用情形

只有案件图片被质量检查或视觉识别标记为模糊、低分辨率、过暗或关键细节不可辨认时，才显示地图辅助复核入口。地图提供补充线索，不能弥补缺失的现场照片、安装证明、产权或并网材料。

## 处理流程

1. 工作台优先展示项目地址；核保员也可选择材料 OCR 提取出的地址，或人工更正。
2. 核保员确认同意把地址发送给高德开放平台。
3. 服务端使用 `PV_AMAP_WEB_SERVICE_KEY` 调用高德 Web 服务地理编码，返回地址候选、地址级别、原始 GCJ-02 坐标和供天气查询使用的近似 WGS84 坐标。高德不返回与百度接口相同的地址理解度/置信分，因此系统不伪造分数；候选必须由核保员人工确认。
4. 核保员选择准确候选。配置了 JS API 凭证时，工作台展示高德卫星图层和位置标记；未配置时提供高德地图定位链接，核保员可在地图页手动切换图层。
5. 核保员记录是否能确认位置、光伏组件可见性、安装载体、可见的影像日期和观察内容。影像时间未知、画面不清或点位不确定时应如实记录。
6. 后端重新解析地址并核对所选候选，再把地址、GCJ-02/WGS84 坐标、地图入口及人工观察追加到案件和报告。记录只作为人工上下文，不改变自动核保结论。

## 卫星影像和自动判断边界

- 高德卫星图层提供地图影像，不是实时卫星监控。影像可能有更新时间差异、日期可能不显示，也可能无法看清屋顶。
- 系统不下载、截图、缓存或转发地图影像，不会将地图画面发送给 Qwen/VLM。自动视觉结论仍只根据投保人提交的原始材料产生。
- 地图看到组件不能证明本项目安装质量、产权或结构安全；地图未看到组件不能证明现场没有组件。
- 地理编码只提供地址候选。核保员必须确认具体位置；WGS84 坐标是对高德 GCJ-02 坐标的近似反算，只用于 Open-Meteo 网格天气查询，不是测绘结果。
- 高德接口不提供与旧百度地理编码流程相同的匹配度/定位置信分。地址级别只作为线索，不转换为系统置信度。

## 配置

在本机 `.env` 设置高德 Web 服务 Key；地图地址解析和常规天气查询使用的 Key 类型不同：

```dotenv
PV_AMAP_WEB_SERVICE_KEY=高德Web服务Key
PV_AMAP_USE_SYSTEM_PROXY=false
PV_AMAP_JS_API_KEY=高德Web端JSAPI_Key
PV_AMAP_JS_SECURITY_CODE=高德JSAPI安全密钥
PV_MAP_TIMEOUT_SECONDS=10
```

`PV_AMAP_WEB_SERVICE_KEY` 用于服务端地理编码。内嵌卫星层需要在高德控制台另建 **Web端（JS API）** Key，并填写安全密钥；Web 服务 Key 不能作为 JS API Key 使用。JS API Key 和安全密钥会在用户同意地址复核后发送给浏览器以加载官方 SDK，因此应在高德控制台限制 Key 的允许域名。高德建议生产环境通过服务端代理转发安全密钥；本项目的浏览器明文配置仅适用于受控的本地演示环境。

服务端高德地理编码默认通过 TLS 直连，以避免本机系统代理导致请求超时；若网络必须经公司代理访问，可将 `PV_AMAP_USE_SYSTEM_PROXY=true`。该设置适用于高德 Web 服务请求，不影响 Open-Meteo。

`GET /ready` 的 `optional_capabilities.map_review_configured` 表示后端检测到 Web 服务 Key；`optional_capabilities.amap_satellite_configured` 表示 JS API Key 和安全密钥都已配置。它们只检查配置是否存在，不会发起联网请求或验证额度。

## 接口

- `POST /api/v1/cases/{case_id}/map-review/prepare`：在明确同意后解析地址，返回候选、卫星层可用状态和影像时效说明；只适用于存在图片质量问题的案件。
- `POST /api/v1/cases/{case_id}/map-review`：核对所选候选并追加核保员的地图观察；需要确认地图页已打开。
- `GET /api/v1/locations/resolve?address=...`：返回地址候选供项目地址/天气查询流程选择。核保员选择候选后，正式核保流水线才会用近似 WGS84 坐标请求 Open-Meteo 历史天气。
