# 光伏组件型号识别与参数工作台

用于测试“组件图像自动识别与局部交叉校验 → 本地目录 → SolarStack / 对应规格书 → 联网 Agent → 参数与来源反馈”的流程。材料中的型号由程序自动核验，不需要用户替程序判断模糊字符。

## 本机使用

打开 http://127.0.0.1:8840/ 。重新启动：在 PowerShell 中执行 `./Start-Workbench.ps1`。

当前电脑自动读取同级 `pv-underwriting-ai-v2/.env` 的大模型配置，以及 Windows 凭据管理器中既有的 SolarStack 密钥。密钥仅在后端使用，不返回浏览器。

## 测试流程

1. 输入完整型号，或上传 PNG、JPEG、WebP、PDF。上传后点击识别，Agent自动读取整页、定位局部并交叉校验，唯一通过校验的型号自动填入查询框。多型号资料保留各型号；证据不足时输出缺口，不用人工猜字或按功率档位补型号。上传限制10MB；PDF最多6页，较长文件请选取相关页。
2. 选择“自动回退”，按本地、API与规格书、联网Agent顺序查询。也可单独测试本地目录或Agent。
3. 查看三项抗灾参数、来源原文、查询步骤和型号规则。查询记录可重新打开，并导出 JSON。
4. 在“核验与反馈”填写问题或核验意见。只有完整型号已确认、具有证据且由用户明确选择的字段，才写入人工核验缓存。

快速示例：`LR5-54HTB-440M`（本地记录）、`JAM66D42-605/MB`（API查询）、`JAM66D42-715/MB`（未知功率核验）、`HT66-210(ND)-F-705`（补参测试）。

## 机械载荷映射展示（2026-10-13）

已取得的背面／正面机械载荷分别在风（抗风吸力）／雪（抗雪压）主卡片显示为“机械载荷映射值”，保留来源、原始字段和方向。正面也承受风正压；映射不构成厂家对该型号风雪口径或设计能力的直接确认。仅凭 API 字段名称不能确认测试／设计口径，未核实前显示“测试／设计口径待核实”。完整型号未确认或字段有冲突时不映射。

搜索区分数值缺失和映射口径核验：已有映射值不重复算作数值缺失，抗雹等缺项仍触发 API 规格书及 Agent 补查；补查时另提示核对机械值的风雪对应、测试／设计口径和安装条件。三项数值均取得（含映射值）时不因直接风雪字段为空而启动补数搜索，核验项保留。

JSON 的 `ui_fields.value` 是展示值，`value_origin=mechanical_mapping` 标记机械映射，`direct_value` 保留直接风雪字段是否取得；顶层风雪原始字段不伪造为厂家直接披露值。`parameter_tasks.missing_values` 列出缺数值项，`verification_targets` 列出已有映射值的口径核验项。历史记录保留原搜索结果，重新查询可获得新版展示和缺项判断。

## 当前自动识别与复测（2026-10-12）

最新报告：`http://127.0.0.1:8840/static/ocr-refinement.html`，摘要为 `web/ocr-refinement-summary.json`。程序保留原图分辨率及无损编码，处理连字符/斜线前后排版空格，按单元格读取跨行型号，自动局部重读。两次不同视图读取一致且有原文字符支持的型号进入可查询结果。小截图保留完整型号区域再放大读取，避免切掉前缀或后缀；混合PDF不再凭标题的字符数跳过扫描正文。

返回 `recognition_status`、`verification`、`auto_query_eligible`、`unresolved_candidates`，以及页面局部原文、坐标和调用轨迹。图片关联查询由后端阻止未通过该材料自动校验的字串。PDF文字层完整型号可按原文字符直接核验。这里核验的是图中字串，型号存在性仍需完整型号检索；同一视觉模型的不同视图有相关误差，不能保证未知赛题图片100%准确。

前次19/23中的4个漏项，在该轮OCR原文里已经正确出现，但旧解析器漏掉带空格的型号。对原OCR响应回放新解析器恢复23/23；最新报告另列重新调用视觉模型的真实接口结果，不把回放冒充OCR识别提升。

## 数据覆盖及取参口径

- 本地目录来自用户提供的组件抗灾参数 Excel，共365条型号记录；其中69条通过当前明确型号与中国市场条件筛选，其余作为候选待核验。
- 规则库覆盖 SolarStack 快照中的150家厂商、10962个型号、2402个系列，包含2066条结构规则。这些是API样本观察规则，不代表所有字母都已有官方释义，也不保证快照之后的新型号覆盖。
- 先查完整型号；系列、功率槽和后缀用于缩小搜索范围。仅命中系列不会使用相近功率产品参数，例如605W不能替代未确认的715W。
- API缺字段时读取对应规格书；有型号、后缀、功率表和版本覆盖证据才取参。已知存在1000V／1500V版本不匹配的文档保留阻断记录。
- 正面／背面机械载荷直接写入 `front_static_load_pa`／`back_static_load_pa`，在“机械载荷原始数据”中显示已取得的数值。正面可对应积雪及风正压，背面常对应风吸力；两者不是严格的“正面只等于雪、背面只等于风”。已有机械值按明确标注的映射值显示在风雪主卡片；厂家明确风雪对应且型号版本适用时，同时回填直接风雪字段，保留方向、测试／设计口径、原文与页码。安装条件给出2400或5400等多个值时，不择大值。
- 测试载荷不自动等同设计载荷，不统一套用1.5安全系数。不同安装条件、版本或来源的冲突值保留待核验；缺失值不填零。
- 联网Agent使用百炼的真实搜索服务，只将接口返回的真实来源作为检索线索，再读取原文。先执行最多2轮厂商官网检索（完整型号、系列），缺字段时再执行1轮机构补充；最多读取4个文档，保留查询预算。官网已补足时不查机构。
- 官网检索明确加入 `site:厂商域名` 与 `filetype:pdf`，优先找到原始PDF直链，减少目录页和新闻页的访问。读取失败会返回HTTP状态及原因代码：脚本／访问校验、访问拒绝、失效链接、超时或连接失败。429／502／503／504及超时最多重试一次；403／406访问防护不反复重试。当前不执行网站校验脚本，也没有浏览器自动读取兜底；PDF直链可用时仍可读取并核验，不能保证所有官网资料可获取。旧历史保留原记录，重新查询才能看到新诊断。
- 来源准入由 `data/source_policy.json` 控制：官网必须是当前厂商已登记的域名；机构仅限已登记的检测／研究／国际组织及机构媒体自己的官方网站。当前登记8家厂商和10家机构，型号结构规则仍覆盖150家厂商，两个覆盖范围不同。其他厂商域名须核验后登记，未知主体不自动采信为官网。
- 排除个人用户、自媒体、论坛、百科、交易平台和评论区；规则在搜索结果、官网内的PDF链接及每次重定向上执行，不能靠标题写“官方”绕过。网页正文中的用户评论区也排除，不从评论提取数值。机构新闻只有明确对应当前完整型号的数值才能补参；行业常识和泛论不转成型号参数。
- 每个Agent参数返回发布主体、来源层级、文档标题、原文、页码／网页位置、原始链接、获取时间和资料披露的发布日期；PDF保留文件哈希。未披露日期不编造。页面“过程与来源”显示实际读取结果和被排除来源的原因，JSON导出也保留这些信息。
- 有网址不表示自动核验通过。个人／未知来源不会作为参数依据；来源无法访问、规格书版本冲突、OCR错误或型号与数值对应不明时保留缺口。旧历史记录会提示其采用旧规则，应重新查询；旧Agent个人／未知来源参数也不能核验入库。
- 工作台负责组件参数资料核验，不判定屋顶、车棚结构或现场安装是否满足承载条件。

## 在组员电脑安装

建议 Python 3.11 或更新版本：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
# 在本机编辑 .env，填写自己的后端密钥与接口地址
./Start-Workbench.ps1
```

联网Agent目前适配阿里云百炼的 DashScope 流式搜索接口。其他兼容大模型可用于OCR／资料阅读，但需要另接真实搜索服务，不能靠模型生成链接代替搜索。

接入包包含源代码、本地衍生目录和结构规则；不包含密钥、上传原件、查询历史、人工缓存或SolarStack完整原始产品库。未带私有索引时仍可通过API在线搜索。

## 接口供其他工作台调用

| 接口 | 用途 |
| --- | --- |
| `GET /api/status` | 配置可用性与覆盖统计，不返回密钥 |
| `POST /api/identify` | multipart文件上传，返回job_id |
| `POST /api/lookup` | JSON型号查询，返回job_id |
| `GET /api/jobs/{job_id}` | 查询执行状态、实际步骤与最终结果 |
| `GET /api/rules?q=JAM66D42&brand=JA%20Solar` | 查看规则 |
| `GET /api/history` | 查询记录 |
| `GET /api/history/{id}/export` | 下载字段证据JSON |
| `POST /api/history/{id}/feedback` | 核验意见与选定字段缓存 |

查询请求示例：

```json
{"model":"JAM66D42-605/MB","manufacturer":"JA Solar","strategy":"auto","use_agent":true}
```

结果 `profile` 保留风雪参数、抗雹直径、正／背面机械载荷、抗雹冲击速度、各字段证据、`ui_fields` 和 `mechanical_fields` 展示状态；三项字段名称为 `wind_load_pa`、`snow_load_pa`、`hail_resistance_mm`。`profile`为空或 `model_match_status`非exact时不得借用同系列参数。`agent.policy` 给出执行规则，`agent.sources` 给出实际读取来源，`agent.excluded_sources` 给出被排除的链接与原因。

服务仅监听127.0.0.1，供本机测试；其他设备接入需另行部署。历史和原件存储在private目录，分享代码时不要一并分享该目录。

## 校验

```powershell
.venv\Scripts\python.exe -m pytest tests -q
```

检查覆盖型号后缀、功率范围、机械／风雪区别、厂家明确对应、冲突保留、搜索来源真实性、私网URL阻断、API失败回退和人工核验缓存。

厂家口径依据：晶澳官网双玻安装手册（2025年上传路径）（手册页码05）将背面对应风、正面对应风和雪；天合182系列2023年安装手册（手册页码12）明确机械载荷为测试值，按1.5系数区分设计值。用于解释及识别规则，不能给其他型号或安装条件批量赋值。详细核实记录见 `载荷口径与来源规则核实_20261012.md`。
